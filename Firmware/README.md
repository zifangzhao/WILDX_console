# Bundled firmware

Current V1 NP bundle: **high-speed FS2 r7**, APP **654824DE**, USB **02FF93A9**,
ABI258 recovery and exact matching fused/component HEX. The r7 GUI is included.
The stack is **not fully verified**; see [scope and evidence](V1/README.md).
Forced full-speed and the private power trial are excluded. Connecting does
not flash or format a device. APP-only updates do not install USB/recovery.

V1Camera and V2 assets/targets remain unchanged and separate:
[V1Camera](V1Camera/README.md), [V2](V2/README.md).
