# Bundled firmware

The current V1 NP bundle is **store2 rc1**, APP **654824DE**, USB **FACEA0D2**,
with the exact checked WILDX **1.0.0.44** executable. See [V1 details and limits](V1/README.md).

compatibility at about0.83 MiB/s; capture roles retain high speed.

V1Camera and V2 assets/targets remain unchanged and are separate targets.
See [V1Camera](V1Camera/README.md) and [V2](V2/README.md).

The catalog checks exact file SHA-256 values. Historical V1 releases are archived.
