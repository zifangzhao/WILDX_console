# WILDX 1.0.0.34

[Download the installer](WILDX_console-Setup-1.0.0.34.exe).

Published on 2026-10-17. This release includes BLE preview/storage controls,
V1 SD-format recovery, continuous GPIO/RTC logging across interrupted NP
recordings, direct Advanced USB-mode buttons, and the latest owner-approved
firmware artifacts. It retains the **Run WILD-X** option after installation.

All 37 extracted runtime/firmware files matched the checked build. See the
[release manifest](release-manifest.json), [checksums](SHA256SUMS.txt), and
[validation and limits](../Note/RELEASE_1.0.0.34_20261017.md). Firmware programming
requires explicit device/image selection; installing never flashes a device.
The V1 camera candidate is a separate manually selected target. New whole-pair,
endurance and implant qualification remain outstanding.

This root holds exactly one final installer. Prior packages and their original
metadata are preserved under [legacy](legacy/). The preceding final is
[archived here](legacy/20261017_before_1.0.0.34/README.md).
