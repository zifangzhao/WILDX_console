# WILDX 1.0.0.35

[Download the installer](WILDX_console-Setup-1.0.0.35.exe).

Published on 2026-10-17. Firmware Update now has explicit **V1 NP (91k/91k)**
and **V1 Camera40 — candidate** target choices. NP remains the default. Each
choice shows its own APP/USB identities and limits and selects its matching
bundled APP. Changing a target never starts an update.

This UI-only release inherits the 1.0.0.34 console features and approved firmware
images. All 37 extracted files match the checked payload; exporter, helpers and
all ten firmware images are unchanged. The installer retains Run WILD-X.
See [validation and limits](../Note/RELEASE_1.0.0.35_20261017.md), the
[manifest](release-manifest.json) and [checksums](SHA256SUMS.txt).

This root contains one final installer. The preceding release and original
metadata are [archived here](legacy/20261017_before_1.0.0.35/README.md).
