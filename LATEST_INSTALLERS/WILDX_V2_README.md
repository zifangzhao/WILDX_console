# WILD-X / V2 firmware

Use the [unchanged WILD-X 1.0.0.138 installer](WILDX_console-Setup-1.0.0.138.exe), then apply the [standalone V2 firmware/catalog update](../Firmware/Updates/WILDX138_V2_1D3262FB_8DE56637_20261025.zip). The updater installs the matching local catalog and firmware files; flashing the device remains a separate Firmware Update action in WILD-X.
