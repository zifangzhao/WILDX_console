# WILDX 1.0.0.60 build inputs

compiled-sources.zip preserves the exact98 compiler/build inputs used for this release, including original line endings. source-inputs.json records their SHA256 hashes. The matching source files are published at their normal repository paths; unrelated working changes are excluded.

The release reuses the checked exporter/resources/dependencies and published V1 F2D80C4F firmware bundle. Packaging does not recompile the application or rebuild firmware. Validation and payload hashes are in LATEST_INSTALLERS/release-manifest.json.
